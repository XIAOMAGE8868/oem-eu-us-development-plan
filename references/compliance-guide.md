# 欧美个护 OEM 合规速查（EU + US 双轨）

> 已核验时间口径：2026-10。标注 `[已查证]` 的事实来自 EUR-Lex/eCFR/FDA/SCCS 原文；`[待补充]` 项下单前须由合规律师/检测机构复核。

## 欧盟（EC 1223/2009 + CPNP）

- 所有产品上市前须完成 **CPSR + PIF**，并在 **CPNP** 通报（输入方责任人 Responsible Person 在 EU 境内）。
- **视黄醇 Reg (EU) 2024/996** [已查证]：面部 0.3% RE / 身体 0.05% RE（2025-11-01 已执行）。抗老乳/精华含视黄醇必须按此限。
- **ZPT（吡硫翁锌）Reg (EU) 2021/1902 全面禁用** [已查证]：去屑须换 **Piroctone Olamine**，洗去类≤1%、驻留类≤0.5%（Annex V）。
- **香精致敏原 Reg (EU) 2023/1545** [已查证]：扩至约 80 项，**2026-07-31 起新投放强制标注**（驻留类 10ppm / 洗去类按项）。含香 SKU 必须核查。
- **水杨酸 Annex III/98** [已查证]：驻留类≤2%，禁用于 <3 岁；美"祛痘"宣称另属 OTC（21 CFR 333.310），EU 走化妆品宣称边界。
- **壬二酸**：EU ≤10%（≥10% 走药品路径）。
- **熊果苷** [已查证]：SCCS 面部≤2%、身体乳≤0.5%。
- **山嵛基三甲基氯化铵 Annex III/287**：驻留类≤3.0%（发用调理）。
- 纳米原料：按 Art.16 提前 6 个月 CPNP 通报。
- 禁词红线（EU）：不得暗示治疗/诊断疾病（药妆界限），如"治疗湿疹/皮炎/足癣/脱发/灼伤愈合"。

## 美国（FDA MoCRA）

- **MoCRA 注册 + 产品列名已强制** [已查证]：设施注册与产品列名（2024-07 起部分可豁免小企业，但眼周接触类无豁免）。
- **GMP**：最终规则未发布，暂按 **ISO 22716**。
- **香氛过敏原 NPRM**：目标 2026-11 发布，待确认。
- **Piroctone Olamine 不在 21 CFR 358.710 去屑专论活性清单内** [已查证]：美国去屑线必须换 **ZPT / 水杨酸** 并走 OTC + Drug Facts 标签；纯化妆品路径不能宣称"去屑/anti-dandruff"。
- **祛痘宣称 = OTC**（21 CFR 333.310），纯化妆品不得宣称"治疗痤疮"。
- 化妆品功效宣称须避免 structure/function 医疗措辞（"治疗脱水""修复受损器官"等禁用）。

## 逐品合规要点速查（本基准 50 品涉及的关键活性物）

| 活性物/宣称 | EU 要点 | US 要点 |
|---|---|---|
| 视黄醇 / 补骨脂酚 | 视黄醇限 0.3%RE面部/0.05%RE身体 [已查证]；补骨脂酚无强制限 | 纯化妆品；禁"抗皱治疗" |
| Piroctone Olamine（头皮） | 驻留≤0.5%/洗去≤1% [已查证] | 不在去屑专论；禁"anti-dandruff"宣称 |
| 水杨酸（BHA） | 驻留≤2%、<3岁禁用 [已查证] | 祛痘=OTC；磨皮/焕肤宣称审慎 |
| 壬二酸 | ≤10% [已查证] | 禁"acne/rosacea 治疗"词 |
| 熊果苷 | 面部≤2%/身体≤0.5% [已查证] | 提亮/均匀肤色可；禁"美白治疗" |
| 果酸(AHA) | pH≥3.5、游离酸≤10%（SCCS 指引） | 加 Sunburn Alert 警示 |
| 蜗牛粘液/透明质酸/依克多因/后生元 | 常规保湿/修护词可 | 常规；禁"治疗脱水" |
| 卸妆/胶束水 | 常规 | 眼周接触类无 MoCRA 小企业豁免 [已查证] |
| 妊娠纹油 | 禁"预防/治疗妊娠纹" | 同左，用"滋养/保湿/改善肤感" |
| 身体香氛/含香 | 按 2023/1545 约80项标注 [已查证] | 待 NPRM |

## 通用禁词红线（逐品标注）

- "预防/治疗妊娠纹"、"生发/防脱发治疗"、"治疗唇炎/烫伤/湿疹/皮炎/足癣"、"治疗痤疮"——一律按医疗边界规避，改用护肤品措辞（滋养/保湿/修护/改善肤感/即时舒缓等）。
