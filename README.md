# 欧美个护 OEM 新品开发计划

面向广州化妆品 OEM 工厂（擅长**液体 + 膏霜**剂型）的技能，一键生成《欧美个护 OEM 新品开发计划》——一份可直接用于产品开发排期与外贸报价的 **50 品 × 10 列**飞书表格。产出自足、可行动：客户拿到即可据此决策下单。

## 功能

- 固定输出 **50 个产品**、**10 列表头**（产品名称 / 建议净含量 / 核心成分 INCI / 合规功效 / 建议包材 / 包材参考图片 / FOB 出厂价 / 起订量 MOQ / 目标渠道 / 上架理由）
- **欧美双轨合规**：欧盟 EC 1223/2009 + CPNP / 美国 FDA MoCRA
- **渠道视角**：独立站 DTC + 阿里国际站 B2B（私标定制）
- 面向三类客户：中小电商品牌方 / 想做自有品牌的批发代理商 / 美容院线加盟店主
- 命名借鉴国外已被教育的热门品类词（如 La Roche-Posay Cicaplast → Cica 修复膏），承接搜索流量
- **剂型红线**：仅液体 + 膏霜/半固体，严禁牙膏、漱口水、止汗棒/皂类/粉剂等非剂型品

## 安装与使用

1. 将整个 `oem-eu-us-development-plan/` 文件夹放入豆包（Doubao）的 Skills 目录（`<skills根目录>/oem-eu-us-development-plan/`）。
2. 在对话中直接说，例如：
   - 「帮我做一份欧美个护 OEM 新品开发计划」
   - 「生成 50 个产品的跨境个护选品表」
   - 「按这个口径扩充/优化现有的私标加工产品清单」
3. 技能会按要求产出飞书表格（10 列表头逐字固定），并自动完成合规落实与自检。

## 开发与规范要点

- **命名铁律**：产品名称列（A 列）只放纯品类/剂型词，不带包材和净含量（正则校验排除 `ml|g|瓶|管|罐|泵|滴管|软管|走珠|包材` 等词）。
- **包材参考铁律**：包材参考图片只引国外品牌实物（Amazon / Cult Beauty / Dermstore / Sephora / Boots / 品牌官网），不用 1688 / 国内电商图。
- 每个产品都要论证「是否值得做成 OEM 加工链接」，弱心智候选直接弃，不硬凑。
- FOB / MOQ 为估算区间，标注 `[一方称]` / `[待补充]`；合规点标 `[已查证]`。
